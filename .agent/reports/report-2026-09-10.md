## 1. Kết quả tổng quát

Chủ dự án yêu cầu tích hợp tính năng TreeSize (jam-software.com/treesize) vào repo để AI "thông minh hơn, chính xác hơn". Quyết định kiến trúc (ADR-010): **port native Rust**, không shell-out sang app TreeSize (closed-source, trả phí, Windows-only → phá ethos free/cross-platform/single binary của repo).

**4 MCP tools mới** (tổng 7 → **11**), tất cả đọc từ entries đã cache trong session scan (`src/insights.rs`):

| Tool | Tương đương TreeSize | Output chính |
|---|---|---|
| `get_tree` | Folder view / treemap |Size đệ quy từng thư mục + `percent` + rollup `(+N more)` giữ tổng chính xác |
| `file_types` | File sizes/types |Size + count theo extension, sort desc |
| `find_duplicates` | Duplicate finder (Personal/Pro) |Nhóm file giống hệt byte (size prefilter → SHA-256 song song), `wastedSize`, kèm `approvalToken` từng file |
| `compare_scans` | Compare over time (Pro) |Diff 2 scan: added/removed/changed + `netDelta` |

## 3. Bugs đã tìm và fix trong phiên

1. **BUG-20260910-001** — rayon `flat_map` với closure trả sequential iterator → không satisfy `IntoParallelIterator`; fix dùng `g.par_iter()` bên trong.
2. **BUG-20260910-002** — `build_tree` trả cây rỗng trên Windows: `summary.root` giữ backslash (`C:\...`) trong khi entry path đã chuẩn hóa forward-slash → prefix match fail; fix chuẩn hóa root trong `insights.rs`.
3. **BUG-20260910-003 (môi trường)** — rustup default là `msvc` nhưng máy thiếu `link.exe` → build bằng `cargo +stable-x86_64-pc-windows-gnu` + w64devkit; đã ghi chú lại trong `00_INDEX.md`.
4. **BUG-20260910-004 (môi trường)** — `python` không có trong PATH, console cp1252 chết ở ký tự `✓` → dùng `py` + `PYTHONIOENCODING=utf-8`.
5. **Docs lệch code** (sửa cùng phiên): WORKFLOW.md mô tả `scan` trả `entries` (thực tế top-level là `entriesCount`, entries KHÔNG trả về) và `analyze` dùng `sort`/`order` (thực tế `sortBy`/`sortDesc`).
