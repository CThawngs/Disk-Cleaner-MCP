## 3. Kiến trúc đã xây

- **Mô hình 2 tầng**: Rust Engine ⇄ AI Agent qua MCP JSON-RPC over stdio
- **6 tools**: `get_system_status`, `list_categories`, `scan`, `analyze`, `delete`, `get_report`
- **Safety Guard bất biến**: blocklist Windows/Unix paths + approval token SHA-256(salt:path) + xóa mặc định vào Thùng rác
- **13 junk categories**: temp, log, cache, browser_cache, node_cache, python_cache, installer, download, backup, archive, crash_dump, thumbnail, other
- **Scan đa luồng**: `jwalk` + `rayon` (metadata, không đọc nội dung file)
- **Cache LRU**: 3 scan gần nhất lưu để tái sử dụng

## 5. Hướng dẫn sử dụng

### Cấu hình MCP client

```json
{
  "mcpServers": {
    "disk-cleaner-mcp": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\disk-cleaner-mcp\\disk-cleaner-mcp.exe",
      "args": []
    }
  }
}
```

### Workflow đề xuất

```
1. get_system_status → xem ổ đĩa, dung lượng, user dirs
2. scan({root}) → lấy scanId + summary
3. analyze({scanId}) → lọc entry + approval tokens
4. delete({scanId, items, permanent: false}) → vào Thùng rác
```

> Safety: Không bao giờ scan `C:\Windows`, `C:\Program Files`, `/usr`, `/boot`. Xóa permanent phải `permanent=true` + `confirm_permanent=true`.

### Tự chạy test

```bash

```
