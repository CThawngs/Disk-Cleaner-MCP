# Disk-Cleaner-MCP v0.6.0 — Cross-Platform Pure-MCP Architecture Specification

## 1. Product & Architectural Invariants
1. **100% Pure Headless MCP Server (Zero UI/GUI):** No GUI windows, no system tray/menu bar daemons, no SQLite favicon scraping, no network update checks (`0` outbound telemetry). Built exclusively for **AI Agents & Coding Agents** (`Claude Code`, `Cursor`, `Codex`, `Antigravity`, `OpenCode`, `Hermes`, `DeepSeek Harness`, `OpenMausBot`).
2. **100% Additive Backward Compatibility:** All 14 existing MCP tools (`get_system_status`, `get_metrics`, `list_categories`, `scan`, `analyze`, `delete`, `organize`, `get_report`, `get_tree`, `file_types`, `find_duplicates`, `compare_scans`, `list_trash`, `empty_trash`) preserve exact `camelCase` parameters and response schemas.
3. **Unified `ScanSession` + `approvalToken` + Recycle Bin Gate:** Every new scanner (`smart_scan`, `scan_browsers`, `scan_app_leftovers`, `scan_startup_items`, `find_large_forgotten`) registers its Cleanup Units / items via `ScanEngine::register_custom_session(...)` so every deletable item carries a CSPRNG-salted SHA-256 `approvalToken` and flows through `delete()` (`dryRun: true` default, `trash` default, `confirmRisk: true` required for `review`/`keep`, `blocked` always rejected).
4. **Hard Sensitive Data Never-Touch Invariant (`safety::sensitive_never_touch_reason`):** Passwords, Cookies, Login Data, Web Data, History, Bookmarks, Favicons, Local Storage, Session Storage, Extensions, Keychains/Vaults/DPAPI, Password Managers (`1Password`, `Bitwarden`, `KeePass`, etc.), and Developer/Cloud Keys (`.ssh`, `.gnupg`, `.aws`, `.azure`, `.kube`, `.env*`, `.npmrc`, `.pypirc`, `.netrc`) are blocked both at scan time AND at `delete()` verification time (`verify_safe_target`).

## 2. New MCP Tools & Engine Upgrades (14 -> 20 Tools)

| Module | MCP Tool(s) | Core Capabilities (Windows + macOS + Linux) |
|---|---|---|
| `src/smart_scan.rs` + `src/ai_stack.rs` | `smart_scan` | Zero-config Allowlist Smart Scan across OS temp/logs/shader caches, Dev/Package caches (`npm`, `pnpm`, `yarn`, `bun`, `pip`, `uv`, `poetry`, `cargo`, `gradle`, `maven`, `go-build`, `nuget`, `Xcode`), and **AI-Stack Surgical Cleaner** (`HuggingFace *.incomplete` vs snapshots, `Ollama` manifest-diff orphan blobs, superseded `Playwright` browser revisions keeping newest, disposable caches of `Cursor`/`VS Code`/`Windsurf`/`Antigravity`/`OpenCode` with Anti-Suicide live process tree lock). Includes `targetFreeBytes` greedy knapsack planner returning compact Cleanup Units (`detailLevel: "brief"` default) + `scanId`. |
| `src/browsers.rs` + `src/leveldb_ro.rs` | `scan_browsers` | Per-browser & per-profile audit across 10 Chromium browsers (`Chrome`, `Beta`, `Canary`, `Edge`, `Brave`, `Arc`, `Vivaldi`, `Opera`, `Opera GX`, `Chromium`) + `Firefox`. Deduplicates Windows `User Data`. 3 strict groups: `disposable_cache` (`safe_to_delete`, or `blocked` if browser process is running via `sysinfo`), `ai_models` (`review`: `OptGuideOnDeviceModel`, `OptGuidePredictionModels`, `OptGuideOnDeviceClassifierModel`, `optimization_guide_model_store`, `screen_ai`, `SODA`), `website_storage` (`review`, opt-in `includeOrigins: bool` default `false`, `persist_snapshot = false`, pure-Rust read-only `leveldb_ro.rs` + `CacheStorage` owner parser, skips `chrome-extension_*`). |
| `src/leftovers.rs` | `scan_app_leftovers` | Cross-platform orphaned app leftover detection comparing installed apps inventory (Win Uninstall Registry + `Program Files`, macOS `/Applications` + `Info.plist`, Linux `.desktop`/Flatpak/Snap) against user data/cache dirs. Splits `safe_leftovers` (`verdict: "review"`) vs `user_data` (`verdict: "keep"`), vendor ignore-list, `minAgeDays` (default 30). |
| `src/startup.rs` | `scan_startup_items` | Cross-platform Startup & Launch Agents audit (Windows `HKCU/HKLM Run` read-only + Startup folder `.lnk`/scripts, macOS `LaunchAgents`/`LaunchDaemons` `.plist`, Linux `~/.config/autostart/*.desktop` + `~/.config/systemd/user/*.service`). Handles unquoted spaces & script hosts (`wscript`, `cmd`, `powershell`), redacts `--token`/`--key`/`--password`/`--secret` CLI args, flags `orphaned: true` when target binary is missing on mounted disk, issues `approvalToken` (`review`) only for user-writable orphaned startup files. |
| `src/health.rs` | `get_hardware_health` | Read-only zero-estimation Battery + SSD SMART Health + **Agent I/O Guardrails** (`ioSafetyLevel`, `avoidHeavyDiskHash`, `minimizeWriteChurn`, `diskPressureAction`). Windows: `powercfg /batteryreport /xml` + `Win32_Battery` + `Get-PhysicalDisk` + non-admin graceful fallback on `Get-StorageReliabilityCounter`. macOS: `system_profiler` + `ioreg` + `smartctl`. Linux: `/sys/class/power_supply` + `/sys/class/nvme` + `smartctl`. Redacts Serial/UUID/WWN. Pure-Rust cross-OS parsers tested on static fixtures across all OSes. |
| `src/large_files.rs` + `src/insights.rs` | `find_large_forgotten` + `find_duplicates` (`blake3`) | Upgrades `find_duplicates` content hashing to `blake3` (SIMD 4-8x speedup; `sha2` stays in `safety.rs`), skips Cloud-Only placeholders (OneDrive `OFFLINE \| RECALL_ON_DATA_ACCESS \| RECALL_ON_OPEN`, Unix `blocks == 0 && len > 0`) and Unix hardlinks `(dev, ino)`. Adds `find_large_forgotten` grouping into 8 semantic kinds (`video`, `archive`, `installer`, `ml_model`, `disk_image`, `audio`, `image`, `document`, `other`) with `minSize`, `unusedDays`, and `accessTimeReliable`. |
