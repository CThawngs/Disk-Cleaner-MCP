# ISSUES LOG

- `OPEN/` — bug đang tìm nguyên nhân/fix
- `FIXED/` — đã fix, giữ vết cho lịch sử

Format: `BUG-YYYYMMDD-<nn>.md` với template:

```md
# BUG-<ngày>-<n>: <triệu chứng>
- severity: high|medium|low
- reproduced: yes|no
- root_cause: <1-3 dòng>
- fix: <try hướng>
- regression_test: <tên test đã viết>
- status: OPEN | FIXED (date)
```
